# Glossary

- Portfolio section: a homepage block such as Hero, About, Skills, Experience, Projects, Contact, or Chatbot.
- Recruiter path: the fast scan a hiring manager or recruiter takes through the portfolio.
- Case study: a richer project summary that emphasizes problem, solution, stack, and impact.
- Content card: a reusable visual block used to present project, skill, or experience information.
- Motion pattern: existing reveal, hover, or scroll-based animation already used in the site.
- Primary CTA: the main action the user should take, such as contacting Tharun or opening a project link.
