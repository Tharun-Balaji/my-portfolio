# Layer 4: Ideation Report - Engineered Dark Redesign

## Goal: Transform Portfolio into a "Premium Engineering Product"

### 1. Strategic Product Pillars
- **"Systems, Craft, Performance":** Every UI element must justify its existence through these three lenses.
- **Story-Led Homepage:** Move away from a "list of items" to a "narrative of impact."
- **Technical Credibility:** Use JetBrains Mono for UI cues to signal "this is an engineered space."

### 2. High-Impact Feature Ideas (PM Perspective)

#### Feature A: "The Impact-First Project Bento"
- **The Idea:** A ranked bento grid where the flagship project has a "Live Impact" badge.
- **Why:** Hiring managers want outcomes. Highlighting "Problem -> Change -> Result" directly in the card layout solves their biggest pain point.
- **Visuals:** Surface layers (#0E1118) with subtle glass effects.

#### Feature B: "The POV Narrative (About 2.0)"
- **The Idea:** Replace the generic "About Me" with a "System Architecture of a Developer" section.
- **Why:** Establishes stack judgment and point of view. 
- **Components:** "Current Obsessions" (Live Feed) + "Engineering Takes" (Short, punchy opinions).

#### Feature C: "Adaptive Motion Tiers"
- **The Idea:** A system that detects device capability and scales motion from Tier 1 (Static) to Tier 3 (3D Enhancement).
- **Why:** Ensures performance and accessibility (Lighthouse 100) while still offering "premium" feel for high-end devices.

### 3. Priority Roadmap
1.  **Phase 1 (Content):** Restructure Hero and Project cards for "Impact-First" messaging.
2.  **Phase 2 (Visuals):** Apply the Dark Premium palette and typography (Syne + IBM Plex Sans).
3.  **Phase 3 (Motion):** Implement the Tiered Motion system.
