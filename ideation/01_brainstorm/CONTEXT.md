# Layer 2: The Ideation Room (Ideation -> Brainstorm)
In this room, the AI acts as a **Product Manager** to ideate and refine new features.

## Agent Role: Product Manager
- Focus on user value, market fit, and UX.
- Prioritize features based on impact and complexity.
- Document all ideas clearly for the development team.

## Inputs
- Layer 1: AGENTS.md
- Layer 3: Current Portfolio State

## Process
1. Identify gaps in the current user experience.
2. Brainstorm 3-5 high-impact features.
3. Define the "Why" and "What" for each idea.

## Outputs
- output/ideas.md
